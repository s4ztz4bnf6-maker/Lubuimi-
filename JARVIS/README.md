# JARVIS — isolated workspace

This directory is a deliberately separated workspace for the JARVIS backend and its operational integration.

## Isolation rules

- JARVIS work belongs only under `JARVIS/` on the `jarvis-isolated` branch.
- Do not edit, rename, delete, or reformat files outside `JARVIS/`.
- Do not import Syracuse/Collatz or APW4/BBMST research sources into this workspace.
- Do not store credentials, private keys, access tokens, production environment dumps, or database exports here.
- Keep the canonical deployable JARVIS source in sync only after its provenance and contents have been checked.

## Current scaffold status

This is a workspace boundary and documentation scaffold only. No production source code has been copied and no Railway deployment has been triggered.

## Public repository warning

The parent repository is public. Everything committed here is publicly readable. Therefore this directory must contain only non-secret documentation and code explicitly approved for public release. Private JARVIS source or operational details must be moved to a private repository before being committed.
