# Exact cycle certificates from the affine valuation cocycle

Date: 2026-10-27  
Status: research specification; not a Collatz proof and not yet Lean-checked.

## The bottleneck we target

The affine identity for a prescribed odd-Syracuse valuation word is already available in `SyracuseAffineRecurrence.lean`:
[
2^A n_m=3^m n_0+C,
qquad A=sum_{j<m}a_j,quad C>0,
]
where `a_j=v₂(3n_j+1)≥1` and the offset is generated by
[
C_0=0,qquad C_{j+1}=3C_j+2^{A_j},qquad A_{j+1}=A_j+a_j.
]
The remaining gap is not algebraic clearing of denominators. It is the connection between an admissible valuation word and a real orbit, followed by a global argument ruling out nontrivial cycles or proving descent.

## New project-specific object: a cycle certificate

For a finite word (w=(a_0,ldots,a_{m-1})), compute (A(w)) and (C(w)) exactly. Define its return defect
[
D(w)=2^{A(w)}-3^m.
]
If this word is realized by a cycle (n_m=n_0>0), the affine identity forces
[
D(w)n_0=C(w).
]
Consequences, all exact:

1. (D(w)>0), since (C(w)>0) and (n_0>0).
2. The only possible starting value for this word is (n_0=C(w)/D(w)). Hence (D(w)mid C(w)) is necessary in integer arithmetic.
3. This candidate is not enough: it must be a positive odd integer and must realize every exact valuation in the word.
4. Exact realization can be checked stepwise by computing (n_{j+1}=(3n_j+1)/2^{a_j}) and verifying that each quotient is an odd positive integer. Equivalently, the relevant affine numerators must have exact 2-adic valuations, not merely be divisible by (2^{A_j}).

This converts a proposed cycle into a finite, falsifiable certificate. It avoids searching arbitrary large starting integers for a fixed word: the word determines at most one candidate start.

## A useful separation of proof obligations

- **Algebraic gate:** prove (2^A n_m=3^m n_0+C).
- **Cycle gate:** prove the fixed-point equation (D n_0=C) and therefore the divisibility/candidate criterion.
- **Realizability gate:** prove that a candidate word has the exact valuations claimed.
- **Global gate:** show no admissible nontrivial cycle exists, and separately exclude nonperiodic orbits that never hit 1.

The first two gates are finite algebra. The last two contain the substantive difficulty. A finite search can find a cycle certificate or rule out all words in a bounded search region; it cannot rule out every length and every word.

## Exact divergence/Collatz distinction

For the accelerated map (T(n)=(3n+1)/2^{v_2(3n+1)}), the Collatz claim is eventual hitting of 1, where (T(1)=1). It is not (n_k	o+infty). The latter is equivalent to having only finitely many returns below each fixed bound and would exclude the desired fixed point. The return-spectrum interface should therefore be used to classify nontrivial recurrent behavior, not as the target theorem itself.

## Lean next steps

1. Add a separate theorem deriving the cycle fixed-point equation from `affine_identity`.
2. Formalize the integer divisibility consequence without introducing division in the core statement.
3. Implement an exact word checker for finite words, retaining positivity, oddness, and valuation equality as explicit conditions.
4. Test it against direct accelerated iteration for all odd starts and words in small bounded ranges.
5. Keep all claims about global termination open until a proof handles arbitrary admissible words and nonperiodic trajectories.

Novelty status: the fixed-point calculation is elementary, and valuation cylinders are standard in spirit. The project-specific contribution is the certificate interface linking the affine offset, the exact word-realization test, and a bounded cycle search. No claim of worldwide priority or of a new Collatz proof is made.
