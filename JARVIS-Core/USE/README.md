# DJO² IA Universal Scraping Engine (USE)
Proprietary — all rights reserved. See ../LICENSE-PROPRIETARY.
Shared service for UARA, Second Good Life, Commercial Engine, Bounty Scout, public-source research and engineering.
Adapters: requests/BeautifulSoup, Trafilatura, Playwright, Crawl4AI, Scrapy. Prefer static extraction; use browser for permitted dynamic content; bounded batch crawling only.
Require reviewed destination policy, robots compliance, rate limits, isolated network egress blocking private/internal addresses and redirects, bounded response sizes, zero-spend, audit, and untrusted-content labeling. Never bypass access restrictions. Authenticated mail uses OAuth/IMAP/SMTP first; isolated authorized browser sessions only as supported fallback.
This scaffold is not a deployed scraper service. Concrete adapters and network isolation must be implemented and tested before production.
