# Third-party agent and software license policy

This document is a technical integration policy, **not** a grant of license to JARVIS source code and not a replacement for the repository owner's license decision.

1. Record the original source URL, version/commit, SPDX license identifier (when present), copyright notice, license URL and applicable API terms before using third-party code or services.
2. An absent, unknown, custom or contradictory license must be marked **manual review**. Public GitHub visibility does not imply permission to copy, modify, distribute or operate a third-party service.
3. For MIT/BSD/Apache-2.0 and other licenses, verify applicable attribution, notice, patent and distribution requirements individually. GPL/AGPL and other copyleft terms require separate compatibility and network-use review.
4. Respect provider API terms, robots/rate limits, credentials, access controls, payment requirements and third-party agent authorization. No unsolicited autonomous interaction.
5. Store provenance and the license decision alongside each integration; review again when upstream versions change.
6. Do not publish personal participant identities, wallet secrets, API credentials or private commercial data in this repository.
7. This policy does not assert that any discovered agent is autonomous, safe, commercially usable, licensed, or available for free.
