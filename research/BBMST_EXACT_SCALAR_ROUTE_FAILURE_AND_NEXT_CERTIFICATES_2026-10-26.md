# BBMST checkpoint: exact failure of the scalar route and certificate-first next step

Date: 2026-10-26

## Current source-reported frontier

The current ProofAtlas Odd Distinct Covering-System Conjecture page (status shown as checked 2026-08-28) reports two independent open obligations:
1. a universal full-prime depth-two (H=2) minimax inequality for every placement of the twenty mixed shallow depth types; and
2. a rank-stable normalized arbitrary-rank continuation.

The page explicitly says its map and retained computations are not proof evidence for the target conjecture. Its route includes a corrected full-p finite boundary interface, a local exact rational DDA certificate for one inherited hard placement, and an exact integer-dual failure of an earlier scalar boundary functional. These remain source-reported and have not been independently reproduced here.

Reference: https://www.proofatlas.ai/collaboration/odd-distinct-covering-system-conjecture/

## A useful exact negative result from the route map

The reported scalar functional has a lower bound Phi_2 >= 50,213, while the target interface allows at most 44,449. The gap is 5,764. This rules out that particular sufficient scalar functional if the source's integer-dual certificate and model are correct. It does not refute the original covering-system conjecture and does not rule out enriched profile states.

This is useful route-exclusion evidence: do not spend further effort optimizing the same fixed scalar boundary functional. The source's recommended response is to increase the cutoff or enrich the state, with the failed dual certificate retained as a regression test.

## Certificate-first protocol

For each selected placement:
1. freeze the exact finite model (prime set, twenty shallow types, exponent padding, correlated shallow measures, root constraints, live-root/tight-cover cuts);
2. store all matrices, RHS vectors, objective coefficients, variable bounds, and candidate primal/dual vectors as integer/rational data;
3. independently verify every constraint with exact arithmetic and calculate the exact objective margin;
4. use the verified local certificates only as components of the universal proof, never as a substitute for covering all placements;
5. only after the full finite minimax theorem is established, address arbitrary rank through a normalized or multi-component potential with a proved per-block distortion budget.

The local DDA margin reported by ProofAtlas is 904171533679889/16038000000000000 (positive), for one placement. This is not a universal certificate family.

## Relation to the published square-free result

Balister, Bollobas, Morris, Sahasrabudhe, and Tiba's supplemental page says the published computation uses C/Gurobi LPs and separate programs for the d_k bounds. The actual source instance and LP witness have not yet been independently retrieved and replayed by this project. The prior exact check of a rounded line only validates decimal consistency, not the original LP model.

Official supplement: https://people.maths.ox.ac.uk/balister/Erdos-Selfridge.html

The square-free-moduli theorem remains a special case. The unrestricted conjecture asks whether every finite cover by distinct moduli greater than one contains an even modulus.

## Next experiment

Priority is not a new generic CRT lemma. It is a reproducible adversarial finite interface:
- materialize the twenty shallow types and all source-specified root placements;
- enumerate/prune every placement with exact rational bounds;
- export one replayable certificate per leaf or a countercertificate identifying a missing state;
- test the scalar route against the exact negative dual certificate, and test any enriched profile on the same adversarial family;
- record a separate proof that exponent padding and correlation assumptions are retained.

Until these steps are done, the full-p minimax and arbitrary-rank obligations remain open. No global theorem or independent reproduction is claimed.
